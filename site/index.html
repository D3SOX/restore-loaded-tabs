Restore Loaded Tabs

Firefox extension

Keep loaded tabs loaded after a restart.

Firefox normally restores inactive tabs as unloaded. This extension remembers which tabs were loaded and restores that state when Firefox starts again.

Get the extension View source

Loaded stays loaded

Tabs that were in memory load again after Firefox restarts.

Unloaded stays unloaded

Discarded tabs remain idle until you select them.

Private by design

No page access, analytics, remote services, or transmitted data.
