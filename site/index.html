Restore Loaded Tabs

Firefox extension

Keep loaded tabs loaded after a restart.

Firefox normally restores inactive tabs as unloaded. This extension remembers which tabs were loaded and restores that state when Firefox starts again.

Add to Firefox View source

Loaded stays loaded

Firefox reloads the same tabs you had loaded before the restart.

Preserve unloaded tabs

Previously unloaded tabs wait until you open them.

Private by design

No page content is read, and no data leaves Firefox.

Source available on GitHub. This extension was written with GPT-5.6 Sol in Codex.
